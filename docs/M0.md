# Milestone M0 — Aplicação Web Funcional

> **Status:** ✅ Concluído
>
> **Período:** Implementação inicial até versão web estável
>
> **Resultado:** SPA React + Vite medindo download, upload e latência com precisão

---

## Objetivo

Entregar uma aplicação web funcional de teste de velocidade de internet, com UI polida, algoritmo adaptativo e todos os bugs críticos corrigidos.

---

## Tarefas

### M0-T1 — Estrutura do Projeto

### M0-T3 — Serviço de Latência (`latencyService.ts`)

- [x] Implementar 10 pings sequenciais via GET `/cdn-cgi/trace?t={timestamp}`
- [x] Usar `AbortController` com timeout de 5s por ping
- [x] Cache desabilitado (`cache: 'no-store'`)
- [x] URL única por ping para evitar cache do browser
- [x] Remover outliers (primeiro e último)
- [x] Calcular avg, min, max e jitter
- [x] **Bug fix:** HEAD → GET + `response.text()` para medir RTT completo

### M0-T4 — Serviço de Download (`downloadService.ts`)

- [x] Fase 1 — Quick Benchmark: baixar 1MB para estimar velocidade
- [x] Fórmula do benchmark: `(bytes * 8 * 1000) / ms / 1e6`
- [x] Fase 2 — Bursts adaptativos: 5 bursts sequenciais com delay de 200ms
- [x] Paralelismo adaptativo: `max(1, min(8, ceil(quickMbps / 10)))`
- [x] Tamanho do burst: `max(5MB, min(25MB, quickMbps * 2MB))`
- [x] `Promise.allSettled()` para requisições paralelas
- [x] Cálculo final: `(totalBytes * 8 * 1000) / totalTime / 1e6`
- [x] **Bug fix:** Adicionar fator `* 1000` para conversão ms → segundos

### M0-T5 — Serviço de Upload (`uploadService.ts`)

- [x] Quick Benchmark: enviar 1MB de zeros
- [x] Fórmula do benchmark: `(1_000_000 * 8 * 1000) / ms / 1e6`
- [x] Bursts adaptativos: 5 bursts sequenciais com delay de 200ms
- [x] Paralelismo adaptativo (mesma lógica do download)
- [x] Tamanho do burst: `max(1MB, min(5MB, quickMbps * 1MB))`
- [x] Body em `Uint8Array` com dados zeros
- [x] Cálculo final: `(totalBytes * 8 * 1000) / totalTime / 1e6`
- [x] **Bug fix:** Adicionar fator `* 1000` para conversão ms → segundos
