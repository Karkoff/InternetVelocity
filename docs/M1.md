# Milestone M1 — Conversão para App Desktop (Electron)

> **Status:** 🔄 Em progresso
>
> **Objetivo:** Transformar a aplicação web em um app desktop Windows instalável usando Electron + Vite
>
> **Estratégia:** `vite-plugin-electron` — integração mínima, zero mudanças no código React existente

---

## Objetivo

Entregar um aplicativo desktop Windows (.exe + installer NSIS) que empacote a aplicação web existente com Electron, permitindo execução fora do navegador sem nenhuma alteração na lógica de negócio ou UI.

## Regras Importantes

1. **Zero mudanças no código React** — `src/` permanece intacto
2. **Zero mudanças nos serviços** — `fetch()` funciona nativamente no Electron
3. **Segurança:** `nodeIntegration: false`, `contextIsolation: true`
4. **Dev mode:** Electron carrega do Vite dev server (`http://localhost`)
5. **Prod mode:** Electron empaceta os assets estáticos de `dist/`

---

## Riscos e Mitigações

| Risco | Probabilidade | Mitigação |
|-------|--------------|-----------|
| `fetch()` não funciona no Electron | Muito baixa | Chromium nativo suporta fetch perfeitamente |
| CORS bloqueia Cloudflare | Nenhuma | Cloudflare permite origens arbitrárias |
| Assets não carregam em prod | Média | Configurar corretamente o path do index.html no main process |
| Build falha no Windows | Baixa | `vite-plugin-electron` é maduro e bem testado |
| Tamanho do bundle muito grande | Baixa (~150MB) | Aceitável para app desktop Windows |
